# Cardiff Split Brand

## Brand Idea

Cardiff Split should feel like the dependable friend who keeps the trip organized without making the trip feel corporate. The product is trustworthy, quick, and privacy-conscious, but it should still feel warm, social, and a little memorable.

The visual anchor is a simplified Cardiff Castle-inspired house/castle mark: a safe shared place for friends, trips, receipts, and settling up.

## Personality

- Trustworthy
- Fast
- Friendly
- Practical
- Lightly playful
- Privacy-aware

Avoid:

- Bank-like severity
- Spreadsheet energy
- Loud fintech gradients
- Generic black-and-white minimalism
- Childish travel-app styling

## Logo Direction

### Concept

A compact castle-house icon with:

- Three simple towers, inspired by Cardiff Castle
- A central door/arch that implies a shared home base
- A subtle split line or negative-space path to reference splitting costs
- Rounded geometry to keep it friendly
- Strong enough silhouette to work as an app icon

### Primary Mark

Use [cardiff-split-mark.svg](assets/cardiff-split-mark.svg) as the first-pass product mark.

The mark is designed to work at:

- App icon sizes
- Favicon sizes
- Social preview avatars
- Header logo lockups

### Wordmark

Recommended text treatment:

- Name: `Cardiff Split`
- Font direction: rounded geometric sans or humanist sans
- Weight: semibold
- Letter spacing: normal
- Case: title case

Good system fallback:

```css
font-family: Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
font-weight: 650;
letter-spacing: 0;
```

## Color Palette

The palette should avoid plain black and white while staying grounded and trustworthy.

### Primary

- Castle Green: `#126C5A`
- Deep Harbor: `#12343B`
- Warm Stone: `#E8DDC8`

### Accent

- Ledger Gold: `#F2B84B`
- Friendly Coral: `#E76F51`
- Sky Glass: `#8ECAE6`

### Neutrals

- Ink: `#18221F`
- Slate Moss: `#52645E`
- Cloud: `#F7F5EF`
- Mist: `#ECE7DB`

## Usage Notes

- Use Castle Green for primary actions.
- Use Ledger Gold sparingly for highlights, paid states, and optimistic settlement moments.
- Use Warm Stone and Cloud for app backgrounds.
- Use Deep Harbor for text-heavy headers or dark surfaces.
- Use Coral only for destructive actions, warnings, or small accent moments.

## UI Feel

Cardiff Split should feel like a refined mobile utility:

- Dense enough to be useful during a trip
- Spacious enough for quick thumb use
- Rounded but not bubbly
- Clear hierarchy
- Clean balances and settlement cards
- Colorful participant avatars
- Friendly empty states without mascot-heavy decoration

Recommended visual motifs:

- Castle arch shapes for empty states and app icon
- Split path/ledger line as a subtle divider
- Participant color chips
- Compact receipt/expense rows

## Voice

Clear, human, and low-friction.

Use:

- "Add expense"
- "Settle up"
- "Mark paid"
- "Who paid?"
- "Split between"
- "Everyone is settled"

Avoid:

- "Financial obligation"
- "Debtor/creditor" in user-facing UI
- "Finalize trip"
- Guilt-heavy copy

## Tagline Options

- Trip splitting without the drama.
- Split the trip, not the friendship.
- Fast, private trip splitting.
- No accounts. No ads. Just settle up.
- The easy way to split trips with friends.

Recommended launch tagline:

> Fast, private trip splitting with friends.
