# Launch Room Web

Product-shaped TanStack Start app for turning rough project ideas into launch plans.

It exercises the reusable Templar primitives behind product behavior:

- auth for a private workspace
- D1 for projects, reports, jobs, artifacts, and events
- R2 for notes and generated report snapshots
- KV for cached dashboard reads
- Queues for deep analysis
- OpenRouter through `@templar/ai` with a local fallback when no API key is configured
